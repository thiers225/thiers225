Je développe des applications web, des pipelines de données et des solutions d’IA pour des besoins métiers concrets. Mon parcours relie **développement logiciel, intelligence artificielle et transformation des systèmes d’information**.

### 📄 DocuFlow · Du document à la donnée fiable

Extraction des champs de factures par **OCR et IA multimodale**, correction humaine et export JSON / CSV. Le projet prévoit un benchmark sur des documents fictifs annotés.

**État :** fondations du backend initialisées ; extraction et interface de validation à développer.  
**Socle :** Python 3.12 · FastAPI · SQLAlchemy · Alembic · PostgreSQL.  
**Interface prévue :** Next.js.

[Explorer le dépôt →](https://github.com/thiers225/docuflow) · [Suivre les tâches →](https://github.com/thiers225/docuflow/issues)
